# 🎵 Way Down We Go — HTML Practice Project

A simple **HTML-based lyrics webpage** created as one of my early projects after learning the fundamentals of HTML.

This project was built after I Commpleted learning HTML, as a way to practice and understand how different HTML elements work together to create a basic webpage.

## 📌 About the Project

The webpage is based on the song **"Way Down We Go" by KALEO**.

It was created mainly for **HTML practice and learning purposes**.

Through this project, I practiced using different HTML elements such as:

* Headings
* Paragraphs
* Links
* Images
* Audio
* Video
* Text formatting
* Preformatted text
* Basic inline CSS styling
* HTML attributes

The page also contains links to the original video and multimedia elements such as audio and video.

## 🛠️ Technologies Used

* **HTML5**
* **Basic CSS / Inline CSS**
* **VS Code**

No frameworks or external libraries were used.

## ✨ Features

* 🎵 Song title and artist
* 🔗 Links to the original YouTube videos
* 🖼️ Song image
* 🔊 Audio player
* 🎬 Video player
* 📝 Lyrics displayed using HTML
* ✨ Different HTML text-formatting elements
* 🎨 Basic styling using inline CSS

The project uses HTML elements including `<h1>`, `<h4>`, `<a>`, `<img>`, `<audio>`, `<source>`, `<video>`, `<pre>`, `<b>`, `<i>`, `<u>`, `<mark>`, `<sub>`, and `<sup>`.
